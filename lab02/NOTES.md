Рабочая папка - это папка на компьютере, которую программа или операционная система использует по умолчанию для поиска, чтения и сохранения файлов во время своей работы.
Индекс - Подготовленное состояние файлов; обновляется командой git add.
Коммит - снимок текущего состояния файлов, подготовленных в индексе, и сохраняет его в историю репозитория.
Git - это программа для отслеживания изменений в коде на компьютере
GitHub - это интернет сайт, на котором хранятся эти проекты, дающие возможность совместной работы над ними.
"Использованные команды":
git status - показывает текущее состояние рабочего каталога и индекса в Git.
git diff - показывает разницу между различными состояниями репозитория
git diff --staged - показывает разницу между текущим состоянием индекса и последним коммитом.
