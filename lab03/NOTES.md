git diff - это команда показывает различия между двумя состояниями, а git show выводит детали конкретного объекта гит. А git log выводит историю коммитов.
log -S"" выводит коммиты где было изменение того, что находится в кавычках
blame выводит автора каждой строки.
git restore вернул последний коммит файла, когда как git restore --source=... возвращает конкретный коммит, который ты напишешь после знака "равно". Использовав первую комманду я верну свой последний коммит, а с последним я верну конкретный коммит, который я сам выберу.
git revert создает новый коммит, отменяющий изменения, а git reset --hard удаляет коммит, который был до сброса. Безопаснее revert, ведь ты не удаляешь коммиты и в любой момент можешь вернуться, что нельзя сделать с reset.
